# dsh-mobile-adapt

给 DSH Web 前端补一层**手机交互与可读性适配**：抽屉式侧栏、滑动手势、可调宽度、触控命中区、软键盘避让、正文字号下限。

纯客户端插件：只注入样式 + 少量 DOM 增补，不改引擎、不改用户的持久化设置。

## 功能

### 抽屉

- **会话侧栏**做成覆盖式抽屉：**右滑打开 / 左滑收起**，手指跟手，松手按位移 + 速度吸附；
- **宽度可调**：60% / 75% / 90% / 100% 四档，**单点按钮切档**、**按住横向拖无极调宽**，松手记住（存 localStorage，按屏宽比例存，转屏不失效）；
- 抽屉内容自动跟随宽度铺满，内部不再留白边。

### 手势

| 手势 | 行为 |
| --- | --- |
| 向右滑 | 打开会话侧栏 |
| 向左滑（抽屉已打开） | 收起侧栏 |
| 系统返回键 | **逐层退出**：先关对话框 → 再关侧栏，都不会直接退出 |

判定规则（避免抢走页面原本的手势）：

- 纵向为主的滑动不接管（`|dx| ≤ |dy| × 1.4`）；
- 起点在可横向滚动的容器里（代码块、表格、长行）不接管；
- 正在选择文本、或打开了模态对话框时不接管；
- 反向滑动直接放弃，不会误开误关。

### 触控与输入

- 手指按下即有按压反馈（只在粗指针设备启用，桌面不受影响）；
- 下拉菜单项最小 44px 高；**不改动现有按钮尺寸**（强改会挤压相邻控件）；
- 去掉双击缩放的 300ms 延迟（`touch-action: manipulation`）；
- 禁止整页回弹，滚动只发生在会话容器内；
- 软键盘弹出时按 `visualViewport` 判断是否遮挡，遮挡则压缩根容器把输入框让出来；
- 输入框聚焦后自动滚回视野；
- 代码块、表格自己横向滚动，长链接/长单词 `overflow-wrap: anywhere`。

### 字号

- 会话正文 **15px 下限**：`--dsh-content-font-size: max(15px, 用户的设置)`，仍然尊重用户调的字号；
- 输入框固定 16px，避免 WebView 聚焦时触发整页缩放；
- 标题、表格、行高等派生字号跟随正文一起变。

## 安装

```bash
bash install.sh                 # 复制插件 + 写挂载行（幂等）
bash install.sh --uninstall     # 删插件 + 删挂载行
```

脚本做两件事：把插件复制到 `$DSH_PROFILE_DIR/plugins/dsh-mobile-adapt/`，并在
`$DSH_PROFILE_DIR/cordis.patch.yml` 末尾追加一段带标记的 `- insert:`。
不需要重启引擎，页面刷新即可生效。

## 可调参数

| 位置（`lib/client.js`） | 作用 |
| --- | --- |
| `PHONE_QUERY` | 生效断点，默认 `(max-width: 767px)` |
| `MIN_CONTENT_PX` | 正文字号下限，默认 15 |
| `WIDTH_STEPS` | 宽度档位循环：默认 `[0.6, 0.75, 0.9, 1]` |
| `DEFAULT_RATIO` / `MIN_RATIO` / `MAX_RATIO` | 首次默认宽度与合法区间（0.75 / 0.35–1.0） |
| `onTouchMove` 里的 `1.4` | 横向判定比；调大更不容易误触 |
| `onTouchEnd` 里的 `0.4` / `0.6` / `0.45` | 打开阈值 / 收起阈值 / 甩动速度阈值 |

改完重新执行 `bash install.sh` 并刷新页面。

## 实现约束

- **不依赖哈希类名**：选择器只用语义属性（`data-phase`、`data-composer-seat`、
  `data-sidebar-collapsed`、`data-sidebar-right-panel`、`data-conversation-session`、
  `class*=sidebarCol` 等），上游换样式哈希不会把它弄坏。
- **不复制状态**：抽屉开合读宿主自带的折叠标记，只镜像成自己的 CSS 开关，永远和布局一致。
- **手势不接管 React**：拖拽只写元素的 inline `transform`，松手走宿主自己的开关接口，
  过渡结束再交还 CSS。
- **几乎不插 DOM**：唯一的控件是侧栏与右栏的宽度按钮。
- **能卸载干净**：控件、样式、观察器、history 记录、inline transform 都在 dispose 里撤销；
  热重载时通过全局句柄显式处置上一个实例。
- **注意 `aria-modal` 的取值**：本环境下该属性值是空字符串，选择器要写 `[aria-modal]`
  而不是 `[aria-modal="true"]`。
- **兼容老 WebView**：没用 `dvh`、`color-mix()`；`:has()` 仅用于设置面板的定向布局。

## 兼容性

与其它往顶栏/侧栏加按钮或文字的插件不冲突：本插件不往顶栏插任何东西，也不强制修改现有按钮的尺寸。
