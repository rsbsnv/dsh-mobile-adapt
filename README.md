# dsh-mobile-adapt

在手机上用 DSH Web，手感更顺一点。

原版界面是按电脑设计的：侧栏挤在一列里、按钮太小不好点、键盘弹出来挡住输入框、字偏小。这个插件把这些都调成适合手指用的样子。

## 功能

**侧栏变成抽屉**

- 右滑打开，左滑收起，手指跟着走；
- 宽度可以调：点一下按钮换一档（60% / 75% / 90% / 满屏），按住左右拖能连续调；
- 调过的宽度会记住，下次打开还是那样。

**手势**

- 右滑：打开侧栏；
- 左滑（侧栏开着时）：收起侧栏；
- 返回键：先关弹窗，再关侧栏，不会一不小心退出 App。

**会话列表好点也好认**

- 标题放大到 16px，长标题**折成两行**显示，不再一刀切成「手机端 dsh 适配手机交…」；
- 每行的时间（6 分钟 / 1 天）保留并放大，随时知道上次是什么时候聊的；
- 行末只留一个 `⋯` 按钮，归档、置顶、重命名都在它弹出的菜单里，不再占三格；
- 按钮放大到 40×40，行高跟着变高，拇指点得准；
- **拖动排序保留原样**：按住标题拖就能调整顺序，插件不拦这个手势。

**点得准**

- 按钮和菜单项放大到手指好按的大小，按下去有反馈；
- 去掉点完要等一下才能点的老毛病。

**键盘不挡输入框**

- 弹出键盘时界面自动往上让，输入框始终看得见。

**字更清楚**

- 正文最小 15px，输入框固定 16px；
- 你要是自己调过字号，插件不会覆盖，只是保证不会小于 15px。

**滚动不跑偏**

- 代码块、表格可以单独左右滑，不会把整个页面拖歪。

## 安装

```sh
bash install.sh              # 安装
bash install.sh --uninstall  # 卸载
```

装完刷新页面就生效，不用重启。

## 想自己调

打开 `lib/client.js`，改这几个：

| 改什么 | 找这个 |
| --- | --- |
| 多大的屏幕才算手机 | `PHONE_QUERY` |
| 正文最小字号 | `MIN_CONTENT_PX` |
| 宽度有哪几档 | `WIDTH_STEPS` |
| 默认宽度 | `DEFAULT_RATIO` |

改完重新跑 `bash install.sh`，刷新页面。

## 兼容

- 不往顶栏加按钮，也不强行改别的插件的控件大小，和大多数插件能一起用；
- 支持 **DSH 0.2 及以后所有版本**（没有写死版本上限，市场里升级到高版本 DSH 也不会被判定不兼容）；
- 只在窄屏（宽度 ≤767px）生效，电脑上不会改变任何东西。
